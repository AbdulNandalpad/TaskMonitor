Task Monitor

Clickable prototype. One area to start, simple login straight to the dashboard. Managers create tasks, import from Excel, manage the workforce and assign. The field team updates by voice and photo.

Demo path

  1. Sign in with user ID and password. One area, so the dashboard opens at once. Try the “Other area” account to see the scope rule.
  2. Manager menu: create a task, import tasks from Excel, workforce (add or import people), assign tasks, report, form settings.
  3. Open a task and tap Edit. Every field change is kept as a version in the history.
  4. Field user signs in, taps the mic or says “Hey Monitor”, confirms, adds a photo.
  5. Generate PDF report. One click.

Watch for

  • Three colours only. Green completed, yellow in progress, red not started.
  • Straight to work. Login, then dashboard. No screens in between.
  • Scoped access. An account from another area cannot sign in here until it is granted.
  • History kept. Editing a task never loses the old values.
  • Voice first. Speak, check, confirm. Transcript and audio stay as evidence.
